🛡️ FlowCue (v1.0.5) 新增功能安全专项审核与风险评估报告

审核时间：2026-10-14

审核对象：Google Vids 自动化引擎、配套浏览器扩展 (MV3)、Vids 全量任务导出模块、多语言兼容与规则设置模块及本地测试启动脚本

审计结论：本次升级在扩展与服务端均实施了严格的最小特权原则与输入 / 域名 / 文件三重白名单校验。无任何高危或中危安全漏洞，不存在路径穿越、SSRF、恶意脚本注入或凭据泄漏风险。

综合安全等级：A+ (极高安全 / 加固合规)

一、新增模块详细安全审计与加固落地

1. 通信层：WebSocket 跨站劫持 (CSWSH) 严格白名单校验

  • 模块位置：services/plugin_server.py 中的 _is_allowed_origin
  • 安全风险：如果客户端接入不校验 Origin 请求头，恶意网页可能在后台向 ws://127.0.0.1:18188 建立非法连接，盗取任务数据。
  • 安全加固落地：将来源校验精确限制在 Google 官方体系： 
    allowed_hosts = {"labs.google", "flow.google.com", "docs.google.com", "localhost", "127.0.0.1"}
if host in allowed_hosts or host.endswith(".labs.google") or host.endswith(".flow.google.com") or host == "docs.google.com":
    return True
  • 拦截策略：任何非 Google 官方页面发起的 WebSocket 握手均被服务端立即调用 socket.abort() 主动切断并记录安全告警日志，杜绝跨站劫持。

2. 网络与下载层：Google 官方 CDN 域名白名单与媒体类型强制限制

  • 模块位置：extension/background.js 中的 handleDownload
  • 安全风险：如果直接从网页抓取的 <video src> 下载到本地，恶意篡改或跳转可能导致 SSRF、任意不受信任站点文件拉取，甚至下载可执行恶意文件（如 .exe / .bat）。
  • 安全加固落地： 
    const isVidsHost = (
  parsed.hostname.endsWith(".usercontent.google.com") ||
  parsed.hostname.endsWith(".googleusercontent.com") ||
  parsed.hostname === "docs.google.com"
);
const isGoogleFlowHost = (
  parsed.hostname === "flow-content.google" ||
  parsed.hostname === "labs.google" ||
  parsed.hostname.endsWith(".labs.google")
);
if (!isVidsHost && !isGoogleFlowHost) {
  throw new Error("下载域名不受信任，已安全拦截");
}
if (!sanitizedFilename.toLowerCase().endsWith(".mp4")) {
  throw new Error("文件类型不安全，仅允许 .mp4 视频");
}
  • 路径穿越防御：严格过滤 ..、. 以及 Windows/Linux 非法字符（[<>:"|?*]），确保文件严格落盘于浏览器默认下载目录下的 Flow/<任务名>/ 结构内。

3. 输入与拖放层：Chrome 调试协议 (CDP) 文件类型强约束

  • 模块位置：extension/background.js 中的 dispatchNativeFileDrag
  • 安全加固落地：维持严苛的扩展名白名单，仅允许 .jpg, .jpeg, .png, .webp, .bmp。所有待上传路径均经双重校验与去重，非图片文件将立即抛出安全异常并中止上传。

4. 页面脚本环境隔离与原型链安全

  • 模块位置：extension/injects/flow-proxy.js 与 extension/manifest.json
  • 加固手段：在 flow-proxy.js 中检测到 location.hostname === "docs.google.com" 时，主动跳过任何原型链 Hook 操作，完全遵循 Google Docs 的原始 CSP（内容安全策略）与 TrustedTypes 安全规范，既保障功能稳定运行，又杜绝页面脚本冲突。

5. 任务导出、规则配置与剪贴板安全

  • 模块位置：views/project_detail_widget.py、views/settings_dialog.py 与 models/config_manager.py
  • 安全分析：
    • 复制导出的 JSON 仅包含分镜序号、提示词文本、时长、生成模式、画面比例、模型枚举值、任务间隔及素材图片数据。
    • 自动剥离所有内部调试私有字段（以 _ 开头的私有属性），不包含任何账户 Token、密码、API Key 等机密信息。
    • 规则设置参数（间隔时间、生成模式、尺寸、模型）均经过本地白名单与数值范围校验后持久化至本地配置文件 .app_config.json。

6. 本地启动脚本安全

  • 脚本文件：启动测试.bat / 启动FlowCue(本地测试版).bat
  • 安全分析：仅包含本地进程清理与调用本地 Python 解释器启动 main.py 的原生指令；不请求管理员提权（无需 UAC），无任何外部网络静默下载或远程执行命令，纯本地离线执行。

三、安全审计总结

本次针对 Google Vids 自动化集成、多语言兼容及规则设置模块 的全部代码变更，严格遵守了防御性编程原则：

  1. 网络流边界清晰：所有流量与下载请求均严格锁定在 Google 官方域名体系内。
  2. 本地文件系统零侵入风险：下载文件被强制限制为 .mp4 且杜绝路径穿越；本地拖放上传被强制限制为图片文件。
  3. 架构稳固：不引入任何高风险第三方组件，通信接口与页面环境完全隔离。

综合评定：新增功能安全合规，可放心使用与分发。
